## 🛠️ Prerequisites & Setup

Before jumping into any of the guides, make sure you have the basics installed:

1. **GitHub Account:** Create a free account at [github.com](https://github.com)
2. **Git Client:** Install Git for your platform via [git-scm.com](https://git-scm.com/downloads)
3. **GUI Tool (Optional):** [GitHub Desktop](https://desktop.github.com/) is helpful for visual tracking.

## 📌 Cheat Sheet Quick Reference

```bash
# Basic Local Workflow
git status                     # Check file status
git add .                      # Stage all changed files
git commit -m "Your message"   # Save snapshot locally

# Remote Synchronization
git clone <repo-url>           # Download repository locally
git pull origin main           # Fetch and merge changes from GitHub
git push origin main           # Push local commits to GitHub

# Branching & Merging
git checkout -b <branch-name>  # Create and switch to new branch
git merge <branch-name>        # Merge branch into current branch
```
